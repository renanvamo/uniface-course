# 2.1 Conceituação de Projeto
Projeto é obrigatório na versão 10 para alguns objetos, mas serve apenas como agrupador

1. Agrupador de objetos
2. Usado para navegar entre objetos com mais facilidade
3. Importar objetos já existentes para dentro do projeto
4. Compilar objetos pertencentes a um projeto
5. Exportar um projeto e os objetos dele (Muito útil para exportar de ambiente de DEV para HOM/PROD)

Objetos que precisam de Projeto

Component
Entity
ApplicationShell
IncludeScript Library
Snippet Library
GlobalProcScript Libaray

# 2.2 Projetos na Prática

Um projeto é uma coleção de referências aos principais objetos de desenvolvimento. Ele é usado para criar e organizar componentes, MODELED ENTITIES e bibliotecas que são necessárias para construir o aplicativo.

Você pode usá-lo para:

Crie objetos de desenvolvimento principais e adicione-os automaticamente ao projeto.
Adicione objetos existentes de desenvolvimento a um determinado projeto.
Abra ou navegue até os principais objetos de desenvolvimento através do projeto.
Compile os objetos pertencentes a um projeto. Serão gerados objetos compilados prontos para execução.
Exporte um projeto e os objetos que ele contém.
Agrupe objetos de desenvolvimento de várias maneiras. Por exemplo, você pode agrupar objetos para refletir a arquitetura do aplicativo, bem como criar projetos ad hoc que contenham apenas os objetos nos quais você está trabalhando no momento.
CARACTERÍSTICAS

Um ponto significativo é que agora o Uniface trabalha com projetos, não há como desenvolver um novo componente, serviço, report, DSP, entidade… se não estiver vinculado a um projeto.
